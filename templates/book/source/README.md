# source/

Pasta reservada à obra-fonte ou a derivados necessários para leitura técnica.

## Possíveis arquivos

- `book.pdf` — arquivo original;
- `book.epub` — arquivo original;
- `book.txt` — texto extraído, quando permitido e necessário;
- `SOURCE_NOTES.md` — observações sobre OCR, páginas ausentes, edição ou acessibilidade.

## Atenção

Não armazene obra integral protegida por direitos autorais em repositório público.

Mesmo quando o arquivo estiver armazenado aqui em repositório privado, `BOOK.md` deve registrar separadamente `STORAGE_SOURCE` e `READABLE_SOURCE`, pois a IA pode não conseguir ler diretamente o binário pelo conector GitHub.
