# books/

Cada obra analisada recebe um diretório próprio:

`books/<slug-do-livro>/`

Estrutura esperada:

```text
books/<slug>/
├── BOOK.md
├── STATUS.md
├── source/
├── analysis/
│   ├── SEGMENTATION.md
│   ├── 01.md
│   ├── 02.md
│   └── ...
├── synthesis/
└── final/
```

## `_inbox/`

Área temporária para entrada de novas obras. Não armazene PDF/EPUB protegido enquanto o repositório estiver público.

## Regra de isolamento

Cada livro deve ser analisado em seu próprio diretório. Não reutilize notas de outra obra como se fossem evidências da obra atual.

Comparações entre livros podem ser feitas posteriormente em documentos específicos, sempre preservando a origem de cada evidência.
