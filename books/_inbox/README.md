# _inbox — Entrada de novos livros

Esta pasta é a área de entrada para uma nova obra antes de ela ganhar um dossiê próprio em `books/<slug>/`.

## Antes de enviar PDF/EPUB

**Não coloque a obra integral aqui enquanto o repositório estiver público.**

Primeiro torne o repositório privado ou forneça o arquivo diretamente ao ChatGPT/File Library.

## Quando houver um novo livro

1. forneça a obra à IA em formato que ela consiga efetivamente ler;
2. se desejar arquivá-la no GitHub, coloque o arquivo aqui somente após tornar o repositório privado;
3. peça para continuar o projeto pelo protocolo canônico;
4. a IA deverá criar o dossiê em `books/<slug>/`, mapear a edição e definir a segmentação.

## Observação técnica

A presença de um PDF/EPUB no GitHub não garante que o conector da IA consiga ler o binário. O estado canônico deve registrar separadamente onde o arquivo está armazenado e como ele foi efetivamente lido.
